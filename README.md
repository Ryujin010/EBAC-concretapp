## 📖 Descripción

Sitio web para una empresa del sector de la construcción, con presentación de servicios y diseño profesional, en donde cualquier cliente puede solicitar una cotización del servicio y colocación de concreto.

## 🛠️ Tecnologías

- **HTML5**
- **CSS3**
- **JavaScript**

## ✨ Características

- Presentación de servicios de la empresa
- Diseño limpio y profesional
- Estructura adaptable a distintos tamaños de pantalla

## 🚀 Instalación y uso

Clona el repositorio:

```bash
git clone https://github.com/Ryujin010/EBAC-concretapp.git
cd EBAC-concretapp
```

Luego:

1. Abre el archivo `index.html` en tu navegador (doble clic), o
2. Usa la extensión **Live Server** de VS Code: clic derecho sobre `index.html` → *Open with Live Server*.
